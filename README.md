# Finance Tracker

A responsive personal finance tracker built with HTML, CSS, and JavaScript. It helps users manage income and expenses, review financial summaries, and keep their data saved locally in the browser.

## Features

### Core Functionality
- Add new income or expense transactions
- Edit existing transactions
- Delete transactions with confirmation
- View dashboard summary for:
  - Total Balance
  - Total Income
  - Total Expense
- Persist transactions using local storage

### Filtering and Sorting
- Search transactions by title
- Filter by transaction type: income or expense
- Filter by category
- Filter by date
- Sort by:
  - Latest
  - Oldest
  - Highest Amount
  - Lowest Amount

### User Experience
- Responsive layout for desktop, tablet, and mobile
- Clean transaction cards with hover effects
- Empty state message when no data is available
- Dark mode toggle
- Modern navbar and polished UI

## How It Works
1. Open the app in a browser.
2. Add transactions using the form.
3. View updates instantly in the dashboard and transaction list.
4. Use the filters and sort controls to explore transactions.
5. Refresh the page and your data will still be available because it is saved in local storage.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## Notes
This project is a front-end-only application and does not require any backend or database setup.
